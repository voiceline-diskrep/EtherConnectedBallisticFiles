# EtherConnectedBallisticFiles

> **Hypersonic Multi-Link Peer-to-Peer File Acceleration over Ethernet**  
> Built with a Swiss Minimalist Strict Monochrome UI, Ballistic Kinetic Particle Engines, and Cryptographic SHA-256 Multi-Link Integrity.

---

## Highlights & Features

- **Strict Monochrome Aesthetic**: Tailored high-contrast palette (`#000000` to `#FFFFFF`) with instant Dark and Light theme switching and reduced-motion modes.
- **Ballistic Particle Accelerator Engine**: High-velocity canvas physics featuring hypersonic streaks, muzzle flash kickback, kinetic impact shockwaves, and trajectory modes (*Hyper-Rail*, *Coil Arc*, and *Quantum Ballistic Scatter*).
- **Tactile Web Audio API Sound**: Synthesized kinetic audio cues (salvo bursts, impact pings, SHA-256 harmonic chimes, and failure alarms) without any external audio asset dependencies.
- **Multi-Link Ethernet Path Aggregation**: Simulated concurrent channel bonding across USB 3.2 2.5 Gbps and integrated 1.0 Gbps PCIe NICs with automatic bottleneck exclusion.
- **Dynamic Chunk Allocation & Failover**: 24-cell adaptive chunk distribution matrix (16 MB blocks) with automatic packet rebalancing upon link disconnect.
- **Cryptographic Device Pairing**: Mutual verification interface with 6-digit PIN and Ed25519 identity verification.
- **12 System State Presets**: Instant simulation of hardware disconnects, firewall blocks, insufficient disk space, and hash mismatch integrity failures.
- **Desktop System Tray Emulation**: Minimize to tray with background transfer tracking and quick flyout controls.

## Quick Start

Open `index.html` in any modern web browser:

```powershell
# In PowerShell:
Start-Process .\index.html
```

Or serve with any static HTTP server:

```powershell
npx serve .
# or Python
python -m http.server 8080
```

## Keyboard & Quick Actions

- **Fire Kinetic Salvo**: Click the **Fire Burst** button in the topbar or press `B`.
- **Toggle Trajectory Mode**: Click the **MODE** pill to switch between *Hyper-Rail*, *Coil Arc*, and *Quantum Scatter*.
- **Drag & Drop**: Drag the sample payload chip or any file from your computer directly onto any online device card.
- **Test Failover**: Click **Disconnect USB 3.2** to trigger instantaneous chunk reassignment to active links.
