Bits vs. Bytes Speed Reference
Network cards report link speed in Megabits/sec (Mbps) or Gigabits/sec (Gbps), while file sizes use Megabytes (MB). 8 bits = 1 Byte:
• 100 Mbps cable link = up to 12.5 MB/s real file transfer speed
• 1.0 Gbps (1000 Mbps) Gigabit Ethernet = up to 125 MB/s real file transfer speed
• 2.5 Gbps Multi-Gig Ethernet = up to 312.5 MB/s real file transfer speed
